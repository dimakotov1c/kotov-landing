# Поиск по имени: kotov.top

Дата проверки: 8 сентября 2026 года.

## Что установлено

- Скриншот Google Search Console от владельца: главная страница есть в индексе Google. Задача — улучшение позиций, а не устранение отсутствия индексации. Отсутствие AMP не является ошибкой.
- Публичная главная, robots.txt и sitemap.xml возвращают HTTP 200. X-Robots-Tag отсутствует; robots.txt разрешает обход. Canonical указывает на https://kotov.top/.
- https://www.kotov.top/ перенаправляет на основной адрес. HTTP-версия и /index.html возвращают 200 без перенаправления; canonical уже задан. Случайный несуществующий путь возвращает 404.
- Перед изменениями локальная страница совпадала с опубликованной по тексту после удаления краевых пробелов.
- Позиция в Яндексе на второй странице известна со слов владельца. Точные позиции по каждому запросу, региону и устройству не измерены.
- Причина низких позиций пока не установлена. Наличие скрытого SEO-текста не доказывает наличие санкций.

## Подготовленные локальные изменения

- В title, description и видимом представлении автора связаны Дмитрий Котов, Дима Котов и специализация 1С.
- Разметка Person связана с ProfilePage; добавлены alternateName и существующий YouTube-профиль.
- Убраны скрытый рекламный текст с повторениями запросов, FAQ без видимых ответов и предложение менторства с невидимой ценой.
- Основной текст видим без JavaScript; анимация подключается для блоков ниже первого экрана при работающем IntersectionObserver.
- Резервный счётчик Метрики перенесён из head в body. Коды подтверждения поисковых систем сохранены.
- Дата существенного изменения в sitemap обновлена. Её следует привести к дате фактического релиза, если публикация состоится позже 8 сентября.

Проверены: единственный H1, уникальность id, внутренние якоря, синтаксис JSON-LD, связи сущностей, canonical, коды подтверждения, XML sitemap и синтаксис всех девяти исполняемых inline-скриптов. Визуальный браузерный тест не выполнен. Изменения пока не опубликованы.

## Публикация

1. Обновить index.html и sitemap.xml в репозитории, из которого публикуется сайт. Адрес репозитория пока не предоставлен. Эта локальная папка не является Git-репозиторием.
2. Если используется GitHub Pages, проверить Settings → Pages → Enforce HTTPS. Для другого хостинга включить постоянный редирект HTTP → HTTPS его средствами. Не добавлять JavaScript-редирект вместо серверного.
3. Проверить после публикации HTTP-ответы, canonical, актуальность файлов, внешний вид на телефоне и компьютере.
4. Запросить индексирование главной в Google Search Console и переобход в Яндекс Вебмастере. Это запрос на обработку обновления, а не способ гарантировать рост позиций.

Перенос на свой сервер ради SEO сейчас не обоснован: текущая страница доступна и проиндексирована. Рассматривать перенос при реальных ограничениях хостинга, необходимости серверного приложения или подтверждённых проблемах доступности.

## Что нужно для дальнейшей диагностики

- Google Search Console → Эффективность → Результаты поиска: экспорт запросов за последние 3 месяца с показами, кликами, CTR и средней позицией; фильтр страницы https://kotov.top/.
- Аналогичная статистика запросов из Яндекс Вебмастера.
- Учитывать страну/регион и устройство: единой позиции для всех пользователей нет. Средняя позиция в отчёте не равна постоянному месту в выдаче.
- В проверке URL раскрыть индексирование: дата обхода и выбранный Google канонический URL. Проверить отчёты о ручных мерах и проблемах безопасности, не предполагая их наличия.

## Приоритет продвижения

Девять уникальных запросов: Дмитрий Котов; Котов Дима; Дима Котов; Дима Котов 1С; Дмитрий Котов 1С; Котов 1С; 1С Котов; 1С Дима Котов; 1С Дмитрий Котов. В исходном списке «Дмитрий Котов 1С» указан дважды.

Сначала оценивать запросы с именем и 1С: их намерение точнее соответствует сайту. По имени без профессии есть конкуренция с однофамильцами; «Котов 1С» тоже неоднозначен. Не создавать отдельные одинаковые страницы под перестановки слов.

После публикации:

1. В принадлежащих владельцу профилях Telegram, YouTube, GitHub, VK и Инфостарт проверить наличие ссылки на https://kotov.top/ и согласованного представления автора. Ссылки на профили с сайта уже есть; обратные ссылки требуют отдельной проверки.
2. При согласовании страниц реальных выступлений указывать этот сайт как личный сайт спикера. Не покупать массовые ссылки и не накручивать переходы.
3. Развивать собственные полезные материалы по 1С и ИИ: оригинальные разборы, записи выступлений с тезисами, примеры кода. Отдельные страницы создавать под содержательные материалы, а не под варианты имени.
4. Карточки статей и видео сейчас создаются JavaScript. При дальнейшем развитии выдавать их содержимое в исходном HTML, сохраняя интерактивность как улучшение.
5. После переобхода сравнивать показатели за сопоставимые периоды, например 28 дней; сначала оценивать показы и запросы, затем позиции и клики. Первое место и срок достижения не гарантируются.
